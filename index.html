Marine Commander

Marine Commander is a host-run battlemap. One GM picks the deck, opens doors, runs the hostiles, hands out turns and keeps the table in sync. Every player controls one character with hit points, inventory and a combat profile; hostiles react to attacks with the original melee AI.

Live sync runs through a public MQTT broker and is encrypted with your session code. It needs no server, so this site can be hosted as static files on Vercel. Share the code (or invite link) only with your table.
